## About me

I'm a security analyst and threat hunter who enjoys finding what others miss. I like
following a suspicious event back to its source, understanding how an attacker operated,
and turning that knowledge into better defences.

## What I do

- **Threat hunting:** looking for attacker behaviour that alerts didn't catch
- **Detection engineering:** building and tuning detections mapped to MITRE ATT&CK
- **Security monitoring:** investigating alerts and separating real threats from noise
- **Blue team research:** learning attacker techniques to improve defence
- **Automation:** using Python to reduce repetitive security work

## What I believe

> Every alert tells a story. The job is to find the real one.
